## About
This project is a private and non-commercial web-application intended to help organize and search through your own wine collection. Data is collected from [Vinmonpolet](https://www.vinmonopolet.no/), and I have plans to get data from [Dagens Næringsliv](https://www.dn.no/smak/vinsok?sort=wtestdd) as well.

## Status
Still doing R&D around viable ways to get information about wines. Current scraping approach violates Vinmonopolets rules stated in their [robots.txt](https://www.vinmonopolet.no/robots.txt) and needs to be changed. I also don't have much extra capacity to work on the project.
